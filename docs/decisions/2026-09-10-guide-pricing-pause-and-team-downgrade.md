# GUIDE 團隊年繳降級與定價暫停點

> Owner Decision：2026-09-10
> 關聯：#120、#48
> 定價 canonical：`docs/decisions/2026-09-03-guide-saas-pricing.md`

## 1. 團隊版年繳中途降回個人版

Owner 選擇：**A，本期維持團隊版到期，下一次續約才降為個人版。**

規則：

- 團隊版年繳當期已付款後，中途提出降級，不立即縮減為個人版。
- 當期仍保留團隊版完整權益與已購席次容量直到原本到期日。
- 不因中途提出降級而退還現金，也不建立 Midao 帳戶折抵金。
- 到下一次續約時，若 tenant 仍選擇個人版，才以當時正式個人版年價續約並切換為個人版權益。
- 降級不得刪除歷史導遊、團次、訂單、付款、退款、通知、報表或稽核資料；新續約週期切到個人版後，多人協作能力依 entitlement（方案權益）限制新操作，但歷史資料與既有訂單必要處理仍保留。
- 本規則與「年繳超額席次中途減少時當期不退款、已購容量保留到期」採相同商業原則。

## 2. 定價暫停點

Owner 明確裁示：**目前定價方面先到這裡，不希望再持續逐題做定價決策。**

因此，自本決策起：

- 現有 `NT$0 / NT$399 / NT$799`、30 張永久體驗額度、5 席團隊版、超額席次 `NT$150／月`／`NT$1,500／年`、年繳付 10 個月用 12 個月，以及已裁示的年繳增減席次／個人升團隊／團隊降個人規則，視為足以支撐目前產品施工的正式價格骨架。
- 尚未決定的 AI 額外用量價格、LINE 額外額度價格、legacy Feature Store／舊點數折抵、月繳／年繳互轉、其他升降級邊角計費、整體 SaaS 取消退款等，統一標記為 `PRICING_DEFERRED`（定價延後），不是一般產品施工的 Owner blocker。
- Agent 不得因 `PRICING_DEFERRED` 而停止 GUIDE 非正式扣款相關的產品、資料模型、UI、測試或文件施工；可以保留明確待定欄位／設定點，但不得自行發明金額或正式退款比例。
- Agent 不得主動把上述延後項目再次逐題詢問 Owner，除非 Owner 主動重開定價討論，或工作已進入 Production subscription billing（正式訂閱扣款）啟用前，而且該未決規則會直接影響真實扣款、發票、折讓或不可逆正式金流行為。
- Production 訂閱扣款、正式價格頁發布、Production migration 或會改變正式收費行為的 runtime main merge，仍需 Owner 明確授權；本次裁示不是該授權。

## 3. 執行方向

這個暫停點的目的，是避免產品交付被大量邊角定價問題切碎。後續優先回到可見、可操作、可持久化的 GUIDE 產品功能與 Midao 前台曝光能力；定價只在真正進入正式收費前再集中收斂。
