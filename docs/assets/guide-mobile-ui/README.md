## 怎麼使用這些圖

這些圖是 **visual baseline（視覺基準）**，用來固定：

- 字體相對大小。
- 卡片與按鈕的尺度。
- 留白與資訊密度。
- 深森林綠／鼠尾草綠／暖白的視覺語言。
- 五個第一層入口的資訊架構。
- GUIDE 行事曆採日期／團次摘要，不採每小時日程格。

它們**不是假資料 seed（測試初始資料）**，也不是 API 契約。圖中的人名、照片、旅客數、回覆率、狀態與日期都只是示意，施工時必須從正式 API／資料庫取得真實資料；沒有資料就顯示空狀態，不能為了看起來漂亮而硬塞示範數字。

## 規格優先順序

- 產品資料與狀態：10、17、18、19 分冊及最新 Owner Decision。
- GUIDE 響應式 UI 與五大入口：`docs/integration/20-GUIDE-RESPONSIVE-UI.md`。
- 本目錄圖片：視覺與資訊密度參考。

若圖片和正式業務規則衝突，**正式業務規則優先**；若施工頁面和圖片的密度／字級／導覽方向明顯不同，**圖片與 20 分冊優先**。
